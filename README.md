# contractor-samples

Portfolio demo sites for **WebsitePlz**. Every company here is **fictional**. Names, owners, phone numbers, license numbers, prices, years and reviews are placeholders, and each page says so in a banner at the top. All pages carry `<meta name="robots" content="noindex">`.

| Tidy Pine Home Cleaning | House cleaning | https://goldjoshua81-dev.github.io/contractor-samples/tidypine-cleaning/ |

Generated from `/workspace/emergency-site/template/` (`images.py` then `build.py`; data in `sites.json` + `extra.py`, styles in `site.css`, logos in `logos.py`, fonts in `fonts.py`).
